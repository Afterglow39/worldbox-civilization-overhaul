專案理念

本專案並非單純漢化。

我的目標是重新設計 WorldBox 所有文明與物種的命名系統，讓每個種族都擁有自己的文化、個性與世界觀。

最初是基於 Inmny 的漢化檔案開始修改，但隨著開發進行，逐步重製並加入大量原創內容，而不是僅僅將文字翻譯成中文。
